# Addidas Sales Dashboard
Title:
👟 Adidas Sales Analysis Dashboard
Adidas Sales Analysis Dashboard – Interactive Power BI Dashboard

📝 Description:
  The Adidas Sales Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI. The project analyzes Adidas sales data to identify important business insights related to sales performance, operating profit, units sold, retailers, regions, states, cities, sales methods, and monthly trends.
  The dashboard is divided into multiple report pages, allowing users to explore the data from different perspectives. Interactive visualizations and filters help users analyze sales performance and identify high-performing regions, retailers, and locations.

🛠️ Tech Stack:
   - Microsoft Power BI –  Dashboard development and data visualization
   - Power Query        –  Data cleaning and transformation
   - DAX                –  Calculated measures and KPIs
   - Excel / CSV        –  Data source and dataset management

📂 Data Source

The dashboard uses the Adidas US Sales Dataset, containing sales-related information such as:

    -Retailer
    -Retailer ID
    -Invoice Date
    -Region
    -State
    -City
    -Product
    -Price per Unit
    -Units Sold
    -Total Sales
    -Operating Profit
    -Operating Margin
    -Sales Method

🚀 Dashboard Features
1. Interactive KPI Cards:
The dashboard displays important business metrics such as:
  - 💰 Total Sales – 899.9M
  - 📦 Total Units Sold – 2M
  - 📈 Operating Margin – 42.30%
These KPIs provide a quick overview of Adidas's overall business performance.
2. Regional Sales Analysis:
Analyzes sales performance across different regions, including:
 - West
 - Northeast
 - Southeast
 - South
 - Midwest
This visualization helps identify the regions contributing the most to overall sales.
3. Retailer Performance Analysis:
The dashboard compares sales performance across major retailers such as:
 - West Gear
 - Foot Locker
 - Sports Direct
 - Kohl's
 - Walmart
 - Amazon
Users can easily identify the top-performing retailers based on total sales and units sold.
4. Sales Method Analysis:
Sales performance is analyzed based on different sales channels:
 - 🏬 In-store
 - 🌐 Online
 - 🛒 Outlet
This helps understand which sales method contributes the most to Adidas's revenue and operating profit.
